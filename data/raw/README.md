# Raw interview data

Place the three source workbooks here:

- `final_codebook_updated_visual.xlsx`
- `interviste_trascrizioni.xlsx`
- `domande_comuni.xlsx`

Workbook files are excluded from Git by the repository's `*.xlsx` ignore rule.
Analysis scripts read them without modifying the originals. Do not commit raw
transcripts or derived transcript text unless the study's consent and data
governance terms explicitly allow it.
